# Simulador-de-Funciones-del-Nucleo-Kernel-de-un-Sistema-Operativo-
Este proyecto consiste en el desarrollo de un simulador del núcleo (kernel) de un sistema operativo mediante una Interfaz de Línea de Comandos (CLI) interactiva en Java. El sistema abstrae y modela el comportamiento de las estructuras y algoritmos fundamentales que gestionan los recursos de la computadora.
